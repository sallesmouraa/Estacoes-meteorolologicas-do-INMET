# Estacoes-meteorolologicas-do-INMET
​Metadados das Estações INMET (BDMEP) ​Repositório contendo o br_inmet_bdmep_estacao.csv, que mapeia estações meteorológicas brasileiras com IDs, nomes, geolocalização e altitude. Essencial para normalizar e integrar dados climáticos em sistemas geográficos e APIs, facilitando o cruzamento de séries temporais com dados demográficos e territoriais.
